Pocket Wilds  v4.2.1  -  คู่มือการเล่น
=====================================

เกม idle RPG บนจอ CYD: สัตว์คู่ใจตะลุยด่านเองตลอดเวลา
คุณคอยลูบหัว อัปเกรด แต่งตัว ตีบวก ใส่การ์ด และพามันไปสู้กับ CYD ของเพื่อน


0. ลงเกม / อัปเดตเกม (Windows - ไม่ต้องติดตั้งโปรแกรมเพิ่ม)
----------------------------------------------------------
ไฟล์ในโฟลเดอร์นี้
  Pocket-Wilds-v4.2.1.bin   ตัวเกม (ไฟล์เดียวใช้ได้ทุกรุ่นจอ)
  esptool.exe               โปรแกรมแฟลชของ Espressif (ใช้ได้เลย ไม่ต้องติดตั้ง)
  flash.bat                 เมนูแฟลช
  update\                   ไฟล์สำหรับข้อ 1 (อัปเดตแบบเซฟไม่หาย) ห้ามลบ ต้องอยู่ข้าง flash.bat

วิธีลง
  1) เสียบบอร์ดเข้าคอมด้วยสาย USB ที่ "ส่งข้อมูลได้" (สายชาร์จอย่างเดียวใช้ไม่ได้)
  2) ปิดโปรแกรมที่ใช้ COM port อยู่ เช่น Serial Monitor, Arduino IDE
  3) ดับเบิลคลิก flash.bat  -> ขึ้นเมนู (ภาษาอังกฤษ) แล้วกดเลข (กดเลขเดียว ไม่ต้อง Enter)

     1. Flash - keep my save       = แฟลช ข้อมูลเดิมยังอยู่  (ใช้อันนี้เป็นหลัก)
        - ลงเกมครั้งแรก และอัปเดตเป็นเวอร์ชันใหม่
        - สัตว์ เลเวล ไอเท็ม เงิน วันเช็คอิน ค่าแตะจอ และค่าสีจอ อยู่ครบ
     2. Flash - erase everything   = แฟลช ล้างเครื่องทั้งหมด  (เริ่มใหม่หมดทั้งบอร์ด)
        - ล้างหน่วยความจำทั้งบอร์ดก่อน แล้วค่อยลงเกม
        - เซฟหายทั้งหมด ต้องแตะปรับจอ (calibrate) ใหม่ สี/ความสว่างกลับเป็นค่าเริ่มต้น
        - มีถามยืนยัน: กด Y = ล้างแล้วลง / กด N = กลับเมนู
        - ใช้เมื่อ: อยากเริ่มใหม่หมด / บอร์ดเคยลงโปรแกรมอื่นมาแล้วเกมรวน / รีบูตวนไม่หยุด
     3. Exit                       = ออก

  4) รอประมาณ 30-60 วินาที ขึ้น [DONE] แล้วกดปุ่ม RST ที่บอร์ด (หรือถอดสายเสียบใหม่)
     กดปุ่มใดก็ได้เพื่อกลับเมนู (แฟลชบอร์ดถัดไปได้เลย) หรือเลือก 3 ออก

- โปรแกรมหาพอร์ตให้เอง และหาไฟล์เกม .bin ในโฟลเดอร์ให้เอง
- รุ่นจอ: ไม่ต้องเลือก เกมตรวจรุ่นจอ (ILI9341 / ST7789) แล้วตั้งสีให้เองตอนเปิดครั้งแรก
  ถ้าสียังเพี้ยน (เหมือนฟิล์มเนกาทีฟ): MENU > Settings > Screen colours แตะสลับ
- อยากเริ่มเกมใหม่เฉยๆ ไม่ต้องแฟลช: MENU > Settings > New game (แตะ 2 ครั้ง)
- เก็บเซฟไว้ก่อนเอาจอไปใช้อย่างอื่น: หน้าติดตั้งบนเว็บ ปุ่ม "เก็บเซฟเป็นไฟล์" แล้ววันหลังกด "คืนเซฟจากไฟล์"
  (ไฟล์ใช้ได้กับบอร์ดตัวเดิมเท่านั้น แก้ไขไม่ได้)

แฟลชไม่ผ่าน?
  - ค้างที่ "Connecting..." : กดปุ่ม BOOT ที่บอร์ดค้างไว้จนเริ่มเขียน (ขึ้น %) แล้วปล่อย
  - ขึ้น [FAILED] / ไม่เจอพอร์ต : เปลี่ยนสาย USB, ลองช่อง USB อื่นของคอม,
    ลงไดรเวอร์ USB ของบอร์ด (ส่วนมากเป็น CH340, บางรุ่น CP2102 / CH9102),
    ปิดโปรแกรมที่จับพอร์ตไว้ แล้วรันใหม่
  - เสียบหลายบอร์ดพร้อมกัน : ถอดให้เหลือตัวเดียว (โปรแกรมจะแฟลชบอร์ดที่เจอก่อน)
  - Mac / Linux : เปิด https://espressif.github.io/esptool-js/ ด้วย Chrome หรือ Edge
    กด Connect เลือกพอร์ต แล้ว
      ลงครั้งแรก / เริ่มใหม่ : ไฟล์ Pocket-Wilds-v4.2.1.bin ที่ 0x0
      อัปเดตแบบเซฟไม่หาย    : update/boot_0x0.bin ที่ 0x0 และ update/game_0xe000.bin ที่ 0xe000 (2 แถว)
    -> กด Program


1. เริ่มเกม
-----------
- เปิดเครื่องครั้งแรกจะมี "TOUCH CALIBRATION": แตะกลางเครื่องหมาย + ทั้ง 4 มุม แล้วแตะกล่อง OK
  (ใช้เล็บหรือปากกาสไตลัสจะแม่นกว่า) ทำครั้งเดียว ทำใหม่ได้ที่ Settings > Touch calibrate
- เลือกไข่ 1 ใน 3 : ไฟ / น้ำ / ใบไม้   (แตะ 1 ครั้ง = เลือก, แตะซ้ำ = ฟัก)
- ตัวละครออกมาแล้ว "สู้เองอัตโนมัติ" ไม่ต้องทำอะไรก็เล่นได้
- โตขึ้นเรื่อย ๆ : BABY -> TEEN (Lv10) -> ADULT (Lv25) -> ร่างสุดท้าย (Lv50)
- ธาตุแพ้ทาง (มีผลใน Arena) : ไฟ ชนะ ใบไม้ / ใบไม้ ชนะ น้ำ / น้ำ ชนะ ไฟ


2. หน้าจอหลัก
-------------
  บนซ้าย  : ชื่อ เลเวล XP / แถบ POW (เต็มแล้วปล่อยท่าไม้ตายเอง) / หัวใจ = ความเชื่อง
            ATK พลังโจมตี  DEF ป้องกัน  SPD ความเร็วโจมตี
  บนกลาง  : ด่าน / ช่องเขียว = ฆ่าไปกี่ตัว (ครบ 10 ผ่านด่าน) / แถบเวลา 60 วินาที
  บนขวา   : เงิน G / นาฬิกา / ความเร็ว 1x 2x

- ทุก 10 ด่านเจอบอส (40 วินาที)
- แพ้ (โดนตีตาย หรือหมดเวลา) -> ถอยไปฟาร์มด่านก่อนหน้าเอง ไม่มีตาย
  พร้อมแล้วกดปุ่ม CHALLENGE กลางจอเพื่อท้าใหม่
- ฉากเปลี่ยนทุก 10 ด่าน: ทุ่งหญ้า ป่า ภูเขา ทะเล ทะเลทราย หิมะ ภูเขาไฟ ถ้ำ กลางคืน บนฟ้า


3. สิ่งที่คุณทำได้บนจอ
---------------------
  แตะตัวละคร (ลูบหัว)   ความเชื่อง +5
  แตะศัตรู              ช่วยตี (+ความเชื่องนิดหน่อย)
  แตะหินม่วงที่ลอยผ่าน   ได้หินตีบวก  ** ปล่อยจอไว้ = ไม่ได้ **
  CHECK IN (ซ้ายบน)     เช็คอิน 7 วัน: เล่นครั้งแรกกดได้เลย แล้วทุก 24 ชม. ที่เปิดเครื่อง
                        ไม่กดก็รอไว้ ไม่มีขาด สะสมจนครบ 7 วัน
                        เงิน = ประมาณฟาร์ม 30 นาที ต่อวัน (วันที่ 7 ได้ไอเท็มท็อป + การ์ด + หินกันแตก)

  แถบเควส (ข้าง CHECK IN) บอกเป้าหมายถัดไป ยังไม่ครบ แตะแล้วพาไปหน้าที่ต้องทำ (มีลูกศรชี้)
                        ทำครบแล้วกระพริบ แตะรับรางวัล (ทำครบในหน้าอัปเกรด/กระเป๋า = เด้งรับให้เลย)
                        เควสแรก ๆ ได้ชุดเริ่มต้น ดาบ เสื้อ ถุงมือ แล้วสอนเก็บหินลอยและตีบวก
                        รางวัล: เงิน ไอเท็ม หินกันแตก หินเสริม การ์ด
  แพ้ด่าน               มีป้ายบอกว่าควรทำอะไร (อัปเกรด ตีบวก ใส่หินเสริม ...)

  ** ความเชื่อง ** ลดลงเองวันละประมาณ 40
     - 50 ขึ้นไป : ใช้ความเร็ว 2x ได้
     - เกิน 99   : 2x กลายเป็น 3x อัตโนมัติ
     - ต่ำกว่า 30 : ตีช้าลง
     - หมดเป็น 0 : มันงอนหนีเข้าไข่!  แตะไข่ 5 ครั้งเพื่อง้อ (ของและเลเวลอยู่ครบ)


4. ปุ่มด้านล่าง
---------------
  UPGRADE : ใช้เงินเพิ่ม ATK / DEF (เพิ่มเป็น % ทบต้น) / ความเร็วโจมตี
            แตะ = ซื้อ 1 ระดับ   กดแช่ = ซื้อรัวจนยกนิ้วหรือเงินหมด
  BAG     : อุปกรณ์ 3 ช่อง  อาวุธ (ATK) / ชุดเกราะ (DEF) / ถุงมือ (ความเร็ว)
  BATTLE  : Tower / Boss Rush / Arena (ดูข้อ 6)
  AUTO    : เปิดไว้ให้แล้ว ความเร็วตามความเชื่อง: ต่ำกว่า 50 = 1x / 50 ขึ้นไป = 2x / 100 = 3x
            แตะเพื่อปิด-เปิด (กดแล้วมีป้ายบอกความเชื่องตอนนี้)
  ! สีแดง  : บนปุ่มล่าง = มีเรื่องใหม่ที่ควรดู เตือนครั้งเดียว เข้าไปดูแล้วหาย
            UPGRADE = ติดด่าน (แพ้แล้วถอยไปฟาร์ม) และมีเงินพออัป
            BAG = ได้ของใหม่ที่แรงกว่าที่ใส่อยู่
            BATTLE = Boss Rush พร้อม, มีเพื่อนมาใกล้ๆ หรือ Tower (เก่งขึ้น 20% จากรอบก่อน)
            เข้าไปแล้วแถวที่มี ! คือเรื่องที่เตือน
  MENU    : สถานะละเอียด (Pet Status), ตั้งค่า (Settings)


5. ไอเท็ม ตีบวก หิน การ์ด  (ปุ่ม BAG)
-------------------------------------
- ไอเท็มมี "เลเวล 1-4" ด่านยิ่งลึกยิ่งมีโอกาสได้เลเวลสูง
  สีกรอบ = เกรด (บอกว่าหายากแค่ไหน ไม่ใช่ว่าแรงกว่าเสมอ) : เทา < เขียว < ฟ้า < ม่วง < ทอง
      คิดจาก เลเวล + มี 2 ช่องขึ้นไป + มี 4 ช่อง + ค่าพลังสุ่มได้ท็อป  (ไม่นับตีบวก หิน การ์ด)
  ของสีเทาขายเป็นเงินให้อัตโนมัติ (ปิดได้ใน Settings)
- กระเป๋าแบ่ง 3 ล็อก ใต้ช่องที่ใส่ : ดาบ 12 / เสื้อ 12 / ถุงมือ 12
  เรียงสีกรอบสูงสุดไว้ซ้ายบน (สีเดียวกัน พลังมากก่อน)
  ล็อกเต็ม = ของใหม่เข้า และขายชิ้นอ่อนสุด (ช่องล่างขวา) เป็นเงินให้เอง  ** ของที่ล็อกไม่ถูกขาย **
  ▲ เขียวที่ไอคอน = แรงกว่าชิ้นที่ใส่อยู่   กุญแจเหลือง = ล็อกอยู่
- แตะไอเท็ม -> ดูค่าพลัง เทียบกับชิ้นที่ใส่อยู่ (+เขียว ดีกว่า / -แดง แย่กว่า)
  EQUIP = ใส่   REFINE = ตีบวก   LOCK / UNLOCK = ล็อกกันขาย   SALVAGE = ขายเป็นเงิน
  ตีบวกสำเร็จ หรือใส่หิน/การ์ด -> ล็อกให้เอง

- ตีบวก (+1 ถึง +10) ใช้หินตีบวก
  ถึง "ระดับปลอดภัย" ติดแน่นอน : Lv1 ถึง +7 / Lv2 ถึง +6 / Lv3 ถึง +5 / Lv4 ถึง +4
  เกินนั้นมีโอกาสพลาด -> ระดับลด 1 (ไม่ต่ำกว่าระดับปลอดภัย)  ** ของไม่มีวันแตก **
  ติ๊ก PROTECT = ใช้หินกันแตก -> พลาดแล้วไม่ลด (เสียหินกันแตกเฉพาะตอนที่มันช่วย)

- ช่อง (รู) 0-4 ช่อง สุ่มทุกชิ้น ไม่เกี่ยวกับเลเวล (4 ช่องหายาก 2%)
  วิธีใส่ : BAG > แตะไอเท็มที่จะใส่ (ชิ้นที่ใส่อยู่ด้านบน หรือชิ้นในกระเป๋าก็ได้)
            > ปุ่มส้ม SOCKET + (มีเมื่อชิ้นนั้นมีรูว่าง) หรือแตะรู (+ เขียว) > เลือกหินหรือการ์ด > SET
  รายละเอียดไอเท็มบอกครบว่ารูทั้งหมดเพิ่มอะไร เช่น +25ATK +160HP +6%ATK
  หน้าใส่ของ: บนสุดเป็นรูปไอเท็มและช่อง (slot) ทั้งหมด ช่องที่กำลังใส่กระพริบเหลือง แตะช่องอื่นเพื่อเปลี่ยน
  หินชนิดเดียวกันรวมค่าให้ เช่น หิน ATK 2 เม็ด = +50ATK
  ** หินและการ์ดเข้า "ชิ้นที่เลือกอยู่" และมีผลเฉพาะตอนชิ้นนั้นถูกใส่อยู่ **
  ช่องละ 1 อย่าง จะหินหรือการ์ดก็ได้ ผสมกันได้
  หน้า GEMS/CARDS มีไว้ดูหิน แถบเศษหิน และสมุดการ์ด (ใส่ของจากหน้านั้นไม่ได้)
  ชุดเริ่มต้นมีรู 1 รู / เควสเลเวล 10 ได้หิน ATK แล้วพาไปใส่ให้ดู
  หินเสริม ATK +25 / DEF +16 / SPD +10% / CRIT +4% / HP +160   (มีแบบเดียว)
            ศัตรูดรอป "เศษหิน" สะสมเต็มแถบ 9 เศษ = หิน 1 เม็ด ให้เอง (ดูแถบที่หน้า GEMS/CARDS)
            หินชนิดไหนใส่ชิ้นไหนก็ได้ค่าเท่ากัน (หิน ATK ใส่เสื้อก็ +ATK)   ถอดออกได้ (เสียเงิน)
  การ์ดมอนสเตอร์ (ตกยาก) : ใส่อาวุธ = ATK+%  ใส่เกราะ = DEF+%  ใส่ถุงมือ = ความเร็ว+%
            Slime 5% / Mushroom 6% / Bat 7% / Ghost 8% / Golem 10% / Dark King 15%
            ใส่แล้วติดถาวร (เกมโชว์ก่อนว่าเพิ่มเท่าไหร่ แล้วค่อยกด SET)
            การ์ดคูณพลังทั้งตัว (พื้นฐาน + อัปเกรด + อุปกรณ์ + หิน) ยิ่งอัปเกรดสูงยิ่งคุ้ม
  สมุดการ์ด : หน้า GEMS/CARDS ไว้อวดว่าสะสมได้กี่ใบ

- เลือกอะไรดี? ตัวอย่าง ดาบ Lv2 ATK 49 ไม่มีรู  vs  ดาบ Lv1 ATK 20 มี 3 รู
    ตอนนี้ Lv2 ดีกว่า  ดาบ 3 รูใส่หิน ATK 1 เม็ดก็ชนะแล้ว (20+25=45 ใกล้ ๆ / 2 เม็ด = 70)
    -> ใส่ Lv2 ไปก่อน แล้ว LOCK ดาบ 3 รูเก็บไว้รอหิน/การ์ด
  ของมีรูหลายช่องเก็บไว้เสมอ ส่วนของไม่มีรู ค่าพลังสำคัญที่สุด


6. BATTLE
---------
  Tower      : ไต่ชั้น ชั้นละ 1 ตัว (30 วินาที) เลือดหลอดเดียวทั้งรอบ ชนะแต่ละชั้นฟื้น 30%
               ทำสถิติชั้นสูงสุดไว้อวด ชั้นใหม่ได้เงินโบนัส ทุก 10 ชั้นใหม่ได้หินกันแตก
  Boss Rush  : สู้บอสทุกตัวที่เคยผ่านรวดเดียว วันละครั้ง ได้ของบอสทุกตัว
  Arena      : สู้กับ CYD ของเพื่อน! เครื่องเห็นเพื่อนใกล้ ๆ เอง (BATTLE ขึ้น ! บอกจำนวนและรหัส CYD-xxxx)
               BATTLE > Arena > แตะชื่อเพื่อน = ส่งคำท้า
               ฝั่งเพื่อนขึ้นป๊อปอัป CHALLENGE! ทุกหน้าจอ แตะ FIGHT! เข้าสู้ทันที หรือ NO
               (ต้องเป็นเวอร์ชันเดียวกัน)

7. ตั้งค่า (MENU > Settings)
----------------------------
  Brightness      ความสว่างจอ 20-100%
  Sound           เสียง ปิด / เบา / ดัง
  Colour tone     โทนสี Normal / Bright / Deep
  Screen colours  สีจอกลับด้าน (เกมเลือกให้เองตามรุ่นจอ ถ้ายังเพี้ยนแตะสลับ)
  Touch calibrate ปรับแตะจอใหม่ (แตะไม่ตรง)
  Auto salvage    ขายของสีเทาเป็นเงินอัตโนมัติ
  Art style       ภาพในเกม: Painted (ภาพวาด) / Pixel (พิกเซลแบบเดิม)
  New game        เริ่มใหม่ทั้งหมด (แตะ 2 ครั้งยืนยัน)


8. สัญญาณ WiFi รอบตัว ใช้ทำอะไร
-------------------------------
- เครื่องสแกนหา WiFi รอบตัวทุก 5 นาที แค่ "นับจำนวน" เครือข่ายที่เห็น
  ไม่เชื่อมต่อ ไม่ใช้รหัส ไม่ใช้เน็ต ไม่เก็บชื่อ WiFi หรือข้อมูลใด ๆ
- ใช้คำนวณค่าเดียวเท่านั้น : แถบ POW (ท่าไม้ตาย) ขึ้นเองทุกนาที
      POW ต่อนาที = (จำนวน WiFi ที่เห็น สูงสุด 10) x (1 + ความเชื่อง / 200)
  เช่น เห็น WiFi 6 เครือข่าย ความเชื่อง 60  ->  POW +7.8 ต่อนาที  (ที่ 2x / 3x ได้เร็วขึ้นตามนั้น)
- ไม่มี WiFi รอบตัว = POW ขึ้นจากการฆ่าศัตรูอย่างเดียว (ตัวละ 5 x ตัวคูณเดียวกัน) เล่นได้ปกติ
- ดูจำนวนที่เห็นได้ที่ MENU > Pet Status  ("WiFi nearby")
- วิทยุ Arena (หาเพื่อนใกล้ ๆ) เปิดอยู่ตลอด และหลบให้การนับ WiFi ทุก 5 นาที


9. เคล็ดลับ
-----------
- ลูบหัววันละไม่กี่ครั้ง ให้ความเชื่องไม่ต่ำกว่า 50 จะได้ 2x ตลอด
- อัปเกรด ATK/DEF สำคัญที่สุด ช่วงแรกซื้อให้เยอะ ๆ
- ติดบอส? ฟาร์มอยู่สักพัก อัปเกรด ตีบวกอาวุธถึงระดับปลอดภัย แล้วค่อย CHALLENGE
- เปิดเครื่องทิ้งไว้ได้เลย เกมเดินเองตลอด (ถอดปลั๊ก = เวลาในเกมหยุด)
